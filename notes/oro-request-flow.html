EE note

The request flow is the same in Enterprise Edition. The differences are inside the steps: website resolution picks the theme and config per website (multi-website), ACL checks include organization ownership, the datagrid applies organization and website scoping, and storefront product data usually comes from Elasticsearch (website search) rather than the ORM.
